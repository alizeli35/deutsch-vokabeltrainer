# Deutsch-Vokabeltrainer — Android-Projekt

Це Android Studio-проєкт, який загортає останню наявну версію тренажера v8 у повноекранний Android WebView-додаток.

## Що включено

- `app/src/main/assets/index.html` — актуальний тренажер із вбудованою початковою базою **371 слова** та вбудованими зображеннями, що були у вихідному файлі.
- WebView із JavaScript і локальним сховищем, щоб прогрес і зміни словника зберігалися між запусками.
- Вибір файлів з Android: додавання фото, імпорт резервної копії JSON.
- Експорт резервної копії у `Downloads/Deutsch-Vokabeltrainer`.
- Усі основні функції вихідного тренажера v8: текстові відповіді, повторення, статистика, редагування/видалення слів і вибір 5/10/30 карток.

**Важливо про OCR фотографій:** розпізнавання тексту використовує Tesseract.js із CDN, тому для OCR потрібне підключення до інтернету. Решта основних функцій та початкова база слів вбудовані в застосунок.

## Як отримати APK

Потрібен Android Studio з Android SDK 35 і JDK 17.

1. Розпакувати архів проєкту.
2. В Android Studio обрати **Open** і відкрити папку `Deutsch-Vokabeltrainer-Android`.
3. Дочекатися Gradle Sync та встановлення запропонованих компонентів SDK.
4. Обрати **Build → Build Bundle(s) / APK(s) → Build APK(s)**.
5. Тестовий APK зазвичай буде створено за адресою `app/build/outputs/apk/debug/app-debug.apk`.

Для встановлення на телефон скопіювати `app-debug.apk` на Android і відкрити його. Якщо Android запитає, дозволити встановлення з цього джерела.

## Як перенести поточний словник і прогрес із браузерної версії

Дані, які були додані або змінені тільки в локальному сховищі браузера, не можна автоматично прочитати з Android-додатка. Щоб перенести саме поточний стан:

1. У старій версії тренажера натиснути **Sicherung exportieren** і зберегти JSON-файл.
2. Відкрити Android-додаток і натиснути **Sicherung importieren**.
3. Вибрати цей JSON-файл.

Так переносяться слова, налаштування та статистика, які містяться в резервній копії. Якщо резервна копія не імпортується, не видаляйте стару версію, доки не буде перевірено дані.
